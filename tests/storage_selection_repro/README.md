# Storage selection-only regression

Run `dotnet run --project tests/storage_selection_repro/StorageSelectionRepro.csproj -p:UseSharedCompilation=false` from the repository root. This compiles the production inventory navigator against minimal scene/input stubs. It checks 6×6 chest discovery, the SixBySixChest extra row, grid and cross-panel routes, unlocked/locked pages, mouse handoff, close cleanup, and a preexisting inventory route. At the left edge of either chest-page row, pressing Left should return to inventory slot 11 (the rightmost slot of the top inventory row); pressing Left on an interior page icon still selects the preceding page icon. The sixth chest row's leftmost slot routes Left to inventory slot 35 (bottom-right). The native `menuStorage/bStorageU` capacity upgrade button is discoverable on its own layer and reachable from a page edge in its direction; locked pages remain excluded. Every selection checks page-index and upgrade metadata so upgrade slot 99 cannot be classified as a page. Disabled upgrade buttons are excluded. It intentionally never simulates item activation or transfer.
