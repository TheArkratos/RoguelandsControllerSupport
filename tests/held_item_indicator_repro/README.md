# Held-item indicator repro

Run `dotnet run --project tests/held_item_indicator_repro/HeldItemIndicatorRepro.csproj -p:UseSharedCompilation=false` from the repo root. This compiles production `ControllerMenuSelection` and `InventorySelectionNavigator` with a stub corner renderer. It checks that controller input moves the held icon to the selected corner and hides the native held graphic, while mouse ownership restores the native graphic at its exact prior scale. The held-state cue persists across inventory, chest, hotkey, stat, and page selections, including page renderer recreation. It also checks that native icon dimensions are passed to the renderer, pickup, placement, swap, and renderer reuse across steady frames. This is a routing test, not a Unity screenshot or pixel-size test; the actual 75% sprite rendering needs in-game validation.
